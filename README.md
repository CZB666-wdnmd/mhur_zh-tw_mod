# 僕のヒーローアカデミア ULTRA RUMBLE 繁體中文化模組

這是一個《僕のヒーローアカデミア ULTRA RUMBLE》的繁體中文化模組。

本專案主要提供遊戲文字的繁體中文化內容，以及方便使用者安裝模組的 Python 安裝器。

## 說明

- 本模組為非官方繁體中文化模組。
- 本倉庫僅公開 Python 安裝器的原始碼。
- 不提供已打包遊戲資源的源文件或原始檔。
- 字體使用 Adobe 的思源黑體與思源宋體。
- 目前翻譯主要為機器翻譯，正在逐步進行人工校對與優化。

## 關於反作弊

本模組在原理上與反作弊相容，但不做任何安全性保證。

使用本模組造成的任何問題或風險，請使用者自行承擔。

## 安裝方式

請前往本專案的 **Releases** 頁面下載最新版本的 `.exe` 安裝程式。

下載完成後，直接雙擊執行安裝程式，依照提示完成安裝即可。

## Python 安裝器使用說明

如果你想自行執行或研究 Python 安裝器，可以下載本倉庫的原始碼後執行安裝器腳本。

一般流程如下：

1. 安裝 Python。
2. 下載或 clone 本倉庫。
3. 進入專案資料夾。
4. 依照安裝器提示執行安裝。

若之後專案內有提供額外依賴或設定說明，請以倉庫內的實際檔案為準。

## 翻譯回報與建議

如果你發現翻譯錯誤、用詞不自然，或有更好的翻譯建議，歡迎在本倉庫提交 Issue。
